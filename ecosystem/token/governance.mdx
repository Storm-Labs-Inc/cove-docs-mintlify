# Governance

At launch, governance will be controlled as follows:

- $COVE token holders via Snapshot
  - Enabling transfers for $COVE
  - Fee switches and settings
  - Funds in the DAO treasury
- Community multisig with input from Gauntlet and core contributors
  - All other operational admin key functionality (parameters, etc.)

Fully on-chain governance (e.g. [Llama](https://llama.xyz/), [OpenZeppelin
Governor](https://docs.tally.xyz/education/governance-frameworks/openzeppelin-governor),
SafeSnap
[Reality](https://docs.snapshot.org/user-guides/plugins/safesnap-reality) /
[oSnap](https://docs.snapshot.org/user-guides/plugins/safesnap-osnap)) will be
launched prior to $COVE being unpaused, at which point the community multisig
will be sunset and the protocol will be completely controlled by token holders.
