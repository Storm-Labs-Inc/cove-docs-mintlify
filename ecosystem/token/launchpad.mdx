## Bazaar Launchpad

Bazaar is a decentralized, chain-agnostic launchpad providing crypto-natives with a fair, community-centric approach to fundraising.

An [uncapped batch
auction](https://docs.bazaar.money/launch/launchpad-mechanics/batch-auctions-capped-and-uncapped)
will be held on [Bazaar](https://bazaar.money/) to help bootstrap protocol
owned liquidity by auctioning 9.5% of the $COVE supply for ETH.

Funds will be used to buy YFI up to 1.5X the value of StakeDAO’s [YFI
supply](https://lockers.stakedao.org/lockers/yfi) (~190 YFI / ~$1.3MM). ~$300K
of the purchased YFI will be used to seed an initial coveYFI/YFI Curve pool as
protocol owned liquidity (PoL).

Excess funds will be held by the community multisig to be utilized by the DAO
through governance.

<Note>
  At the moment, $COVE is non-transferable and only used for voting in protocol
  governance. In the future, we expect governance proposals to enable transfers
  and add additional utility and tokenomics.
</Note>

For more details on $COVE, please refer to the [token
documentation](ecosystem/token/info).

### Auction parameters

| Parameter              | Value                  |
| ---------------------- | ---------------------- |
| Auction type           | Uncapped batch auction |
| Auction start date     | April 22nd, 2024       |
| Auction duration       | 3 days                 |
| % of token supply sold | 9.5%                   |
| Reserve implied FDV    | $30MM                  |
